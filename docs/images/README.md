# Hình ảnh và tài liệu trực quan

Thư mục này dùng để lưu các tài liệu hình ảnh liên quan đến dự án, bao gồm:

- thiết kế hệ thống
- sơ đồ khối
- hình ảnh kết nối phần cứng
- ảnh chụp thử nghiệm

## Cấu trúc đề xuất

- design/: lưu các tài liệu thiết kế và bản vẽ liên quan
- block_diagram/: lưu sơ đồ khối chức năng và kiến trúc hệ thống
